# Tribute Page

A visually engaging tribute page built with HTML and CSS as part of the Oasis Infobyte Internship Program.

📌 **Project Description**

The Tribute Page is dedicated to Formula 1 legend Sebastian Vettel. It mimics a modern sports website interface (inspired by the official F1 site) while honoring his career.

The project demonstrates core web development concepts such as:
- Semantic HTML tags
- CSS Grid & Flexbox
- Responsive Web Design
- Typography and Custom Fonts
- Advanced CSS styling (gradients, text-stroke, hover effects)
- UI/UX Design matching

✨ **Features**

🎨 **Visual Design**
- **Modern UI**: Replicates the official F1 red-themed driver pages seamlessly.
- **Responsive Layout**: Adjusts beautifully for mobile, tablet, and desktop screens.
- **Typography**: Uses distinct fonts for headings (`Teko` - sans-serif) and body (`Inter` - sans-serif) for high contrast and modern readability.
- **Dual Backgrounds**: Transitions from a deep F1 red gradient in the hero section to a dark motorsport theme for the biography.

📖 **Tribute Content**
- **Biography Section**: Detailed 3-paragraph summary of Sebastian Vettel's iconic career.
- **Prominent Imagery**: Uses royalty-free images from Wikimedia Commons with CSS blending (`mask-image`).
- **Statistics Card**: A sidebar card detailing his career points, podiums, and championships just like the official site.
- **Quote Block**: Distinctly styled block highlighting a famous quote.
- **Timeline/Achievements**: Styled cards mapping out his 4 World Championship years (2010-2013).

🛠️ **Technologies Used**
- HTML5
- CSS3
- Google Fonts (`Teko`, `Inter`)
